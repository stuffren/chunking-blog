自定义域名之9-验证github官网IP地址的几种方法

2026年7月28日 Blog github-pages-custom-domain

问题12：有哪些方法可以确认你刚才提供的4 个 A 记录指向 GitHub Pages 的 IP 地址，是github官网的IP地址?


我来帮你搜索 GitHub 官方文档，确认这些 IP 地址。

我已经通过搜索确认了这些 IP 地址。以下是你可以用来验证的几种方法：

方法一：查看 GitHub 官方文档（最权威）

GitHub 官方文档明确列出了这 4 个 IP 地址：

IP 地址 说明
185.199.108.153 GitHub Pages 服务器 IP
185.199.109.153 GitHub Pages 服务器 IP
185.199.110.153 GitHub Pages 服务器 IP
185.199.111.153 GitHub Pages 服务器 IP

官方文档地址：

  • 英文：https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site
  • 中文：https://docs.github.com/zh/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

在文档中搜索 "Configuring an apex domain" 或 "配置 Apex 域" 部分，可以找到这 4 个 IP 地址的明确说明。

方法二：命令行验证（最实用）

你可以通过以下命令自行验证：

1. 查询 GitHub Pages 的 IP 地址

# 查询 github.io 的 IP 地址
nslookup stuffren.github.io

# 或者使用 dig（如果已安装）
dig stuffren.github.io +short

预期输出：

185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153

2. 验证 IP 归属

# 查询 IP 归属信息
nslookup 185.199.108.153

预期输出：

153.108.199.185.in-addr.arpa    name = cdn-185-199-108-153.github.com.

可以看到这些 IP 的反向解析域名都包含 github.com，确认属于 GitHub。

方法三：在线工具验证

工具 网址 操作
IPAddress.com https://www.ipaddress.com 输入 IP 查询归属
站长工具 https://tool.chinaz.com/nslookup 查询域名解析的 IP
IP138 https://www.ip138.com 查询 IP 归属地

验证步骤：

  1. 访问 https://www.ipaddress.com
  2. 输入 185.199.108.153
  3. 查看 "ISP" 或 "Organization" 字段，应该显示 "GitHub, Inc."

方法四：通过 GitHub 仓库设置页面验证

  1. 进入你的仓库 Settings → Pages
  2. 在 Custom domain 输入框下方，GitHub 会显示推荐的 DNS 配置
  3. 如果输入 envjs.fun，GitHub 会提示你添加这 4 个 A 记录

验证结果汇总

验证方式 结果
GitHub 官方文档 ✅ 明确列出这 4 个 IP
命令行 nslookup ✅ 解析到 github.io 的 CDN 节点
IP 反向解析 ✅ 域名包含 github.com
在线工具查询 ✅ 归属 GitHub, Inc.

结论

这 4 个 IP 地址确实是 GitHub Pages 的官方服务器 IP，可以放心使用。如果你仍然担心，建议：

  1. 优先查看 GitHub 官方文档（最权威）
  2. 使用命令行自行验证（最可靠）
  3. 在 Hostinger 后台添加记录后，用 nslookup envjs.fun 验证解析是否生效
